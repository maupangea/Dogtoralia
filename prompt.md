# Dogtoralia - Veterinary Services Platform

## Project Overview
You are an experienced .NET developer building a veterinary services catalog application. This application allows pet owners to find the best veterinarian available in their area and helps veterinarians offer and promote their services online. The application is similar to Doctoralia (https://www.doctoralia.com.mx/) but specifically for veterinary services.

## Objective
For this first iteration update the current MVC generic template project in @DogtoraliaMVC to create an application that displays a list of veterinarians and pets registered, creating the corresponding models, views/view models and controllers for an initial setup.

## Required Features
1. **Two main views:**
   - Veterinarians
   - Pets

2. **Veterinarians Features:**
   - Display the list of registered clinics
   - Create, edit or delete clinics
   - Filter the clinics by speciality and return the results in paginated list

3. **Pets Features:**
   - Display the list of registered pets
   - Create, edit or delete pets


## Technical Requirements

### Application Structure
- .NET MVC application
- Database integration with EntityFramework Core with SQLServer.

### Development Requirements
1. **Seed data:**
    - Create seed data for both veterinarians and pets to display in the application

2. **Testing:**
    - Write comprehensive tests where needed covering:
        - Test happy paths
        - Test edge cases
        - Test error states

2. **Build Quality:**
   - The EntityFramework migrations should be created and run without errors
   - The project must compile and build successfully without errors


## Deliverable
A working .NET MVC application that demonstrates the core domain model and basic functionality of the Dogtoralia platform. Finish creating the corresponding documentation and write context to CLAUDE.md for next iterations.
